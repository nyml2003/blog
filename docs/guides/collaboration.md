# 协作指南

涉及跨职能计划时，由一名项目经理负责目标、范围、分工、依赖和集成验收。项目经理不直接替代专业实现或视觉产出；小范围单人任务可以不设独立项目经理。

产品负责人保留产品目标、永久事实和公共契约的最终决定权。项目经理可以自主调整执行顺序、任务分工和实现细节，但不能自行改变这些边界。

Subagent 交付必须包含：修改范围、测试命令、结果、未解决问题和文档影响。临时讨论不作为长期事实来源。
