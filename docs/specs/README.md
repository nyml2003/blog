# 行为 Spec

Spec 描述必须满足的可观察行为和契约。稳定 Spec 使用 `SPEC-*` ID，可以被实现、测试和后续任务直接引用，不依赖某个固定的计划目录。

早期允许轻量 Spec，但跨职能行为、公共接口、状态迁移和对外可观察行为必须在确认前完成测试或人工证据映射。是否配套计划由工作规模决定。

常用状态：

- `draft`：仍在讨论，不能作为实现授权；
- `confirmed`：行为决策已经确认，但实现、证据或产品验收仍需单独判断；
- `accepted`：当前采用的行为契约；不表示所有未来扩展都已完成；
- `superseded`：已被新 Spec 或明确决策替代。

`specs/archive/` 是保存位置而不是完成证明。归档文件可能保留当时的 `accepted`/`archived`
front matter 作为历史原貌，但不再优先于当前目录中的 Spec 和最新明确决策。

使用 [_template.md](./_template.md) 创建新 Spec。
